# Knowledge Cosmos

知識のつながりを3D宇宙空間として可視化する、個人向けナレッジグラフ（iPhone優先のWebアプリ）。

## 現在できること（最初のプロトタイプ）

- 3D宇宙空間に知識を星として表示（初回はサンプル5個）
- 1本指ドラッグで視点を回転、2本指でズーム・移動
- 星をタップ → 下から詳細パネル（ボトムシート）
- 知識の追加・編集・削除（削除時はつながりも一緒に削除）
- 「⟷ つなぐ」で2つの星を接続（関係の種類と理由を保存）
- 「✥ 動かす」で星をドラッグして自由配置
- データは端末内（IndexedDB）に保存され、閉じても残る

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm run build   # 本番用ビルド（型チェック込み）
```
