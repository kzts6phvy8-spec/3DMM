# A. 情報の構造

## 3-1. 全体の関係図

```
                        ┌──────────┐
                        │   宇宙    │  ← すべての知識が入る1つの空間
                        └────┬─────┘
                             │ たくさん含む
                             ▼
   ┌───────── 意味のつながり（自分で結ぶ） ─────────┐
   │                                                │
┌──┴───┐                                        ┌───┴──┐
│  星   │ ◀──── 言及のつながり（リンクから自動）── │  星   │
└──┬───┘                                        └──────┘
   │ たくさん持つ
   ▼
┌──────┐  [[リンク]]で別の星を指す
│ 記述  │ ─────────────────────────▶ 星（登録済み／まだ知らない星）
└──┬───┘
   │ 0個以上の出典を参照する
   ▼
┌──────┐
│ 出典  │  ← 1つの出典を、たくさんの記述から使い回せる
└──────┘
```

## 3-2. それぞれの決まり

### 星

- 宇宙の中の1つの項目。
- 状態は2つある。
  - **登録済み**：概要や記述がある。
  - **まだ知らない星**：どこかの記述でリンクされただけで、中身がまだない。
- 「まだ知らない星」に概要か記述を1つ書くと、自動で「登録済み」になる。
- 同じ名前で別のものを指す星は、**区別用の補足**を付けて分ける。
  - 例：「マーキュリー（惑星）」「マーキュリー（神話）」
  - リンクや検索の候補では、補足まで表示して選び間違いを防ぐ。
- 星には**固有のアドレス**を持たせる。
  - 例：`…/#/star/ソクラテスのID`
  - Webでは、このアドレスでブラウザの「戻る」が効く。他の画面から直接その星を開ける。
  - アプリでも同じ考え方を使う。

### 記述

- 必ず**1つの星に属する**。
- 区分は**事実**か**意見**のどちらか。
- 本文の中の `[[言葉]]` は、星を**IDで**指す。
  - 星の名前を変えても、リンクは切れない。表示は新しい名前になる。
- 1つの星の中の記述は、自分で並べ替えられる。
- 記述には、任意で**話題**を付けられる。
  - 例：語源・定義・歴史・人物・数値
  - 星のページでは、話題ごとにまとめて読める。
  - 語源も事実なので、他の記述と同じく出典と確認状態を持つ。

### 出典

- 星や記述から**独立して存在する**。
- 複数の記述（と、意味のつながりの理由）から参照される。
- どこからも使われていない出典は、「出典一覧」に残る。不要なら自分で消す。

### 確認状態（事実の記述）— 2026-11-13に廃止。以下は当時の記録

自動で決まるものと、人が決めるものがある。

```
 出典0個 ───────────▶ 未確認（自動）
 出典1個以上 ────────▶ 出典あり（自動）
 出典を自分で読み、一致を確かめた ─▶ 確認済み（人が付ける）
 食い違いや反対の根拠を見つけた ──▶ 異論あり（人が付ける）
```

- 「確認済み」は、**出典が1個以上あるときだけ**付けられる。
- 確認済みの記述の**本文を書き換えた**場合
  - 状態は「出典あり」に戻る。内容が変わったので、もう一度確かめる必要があるため。
- 確認済みの記述から、**最後の出典を外した**場合
  - 状態は「未確認」に戻る。
- 状態が変わったときは、いつ・なぜ変わったかを記録に残す。

### つながり

**言及のつながり**

- 記述の中のリンクから**自動で計算**する。保存はしない。
- 事実の記述からのリンクは実線、意見の記述からのリンクは点線として扱う。

**意味のつながり**

- 自分で作って保存する。
- 持つもの：種類、理由（事実か意見か）、出典、確認状態。
- 向き（どちらからどちらへか）は、種類によって決まる。

| 種類 | 向き | 例 |
|---|---|---|
| 因果関係 | あり（原因 → 結果） | 産業革命 → 都市化 |
| 応用・発展 | あり（元 → 発展） | 問答法 → ソクラテス式教育 |
| 歴史的関係 | あり（先 → 後） | ソクラテス → プラトン |
| 部分と全体 | あり（部分 → 全体） | ソクラテス → 古代ギリシャ哲学 |
| 類似性 | なし | |
| 対立・反論 | なし | |
| その他 | なし | |

- 同じ2つの星の間に、**種類の違う**意味のつながりを複数作れる。
  - 例：「歴史的関係」と「対立・反論」の両方を持つ師弟

### 星の確かさ（まとめて見る値）

- 星の中の**事実の記述**の確認状態を集計する。
  - 例：「事実5件中、確認済み4件」
- 宇宙の中で、確かな星とそうでない星を見分けるのに使う（見せ方は表層で決める）。

### 連続記録（2026-11-14に追加）

- 知識のデータとは別に、`activity-v1` に「クイズ・パズルをやった日（YYYY-MM-DD）の一覧」として保存する。
- 一覧で持つのは、端末をまたいで合わせるときに、一覧を足し合わせるだけで済むようにするため。
- バックアップに含める。復元するときは、今の記録と足し合わせる（消さない）。
- 起動時のカードを今日出したかは、端末ごとに覚える（`localStorage` の `cosmos-streak-card`）。

### 関わり方の記録（2026-11-13に追加）

- 知識のデータ（`cosmos-v2`）とは別に、`engagement-v1` に保存する。
- 星が選ばれたとき（タップ・リンク・検索など、方法は問わない）に「開いた」と数える。
  - 10分以内に同じ星をもう一度開いた場合は、同じ1回と数える（行ったり来たりで増えすぎないように）。
- 加えた記述・結んだつながりは保存せず、データから数える。
  - 初期セットから入ったもの（IDが `starter-` で始まる）は数えない。
- バックアップに含める。復元するときは今の記録と合わせ、記録は減らさない（回数は大きいほう）。
- 星を消しても記録は残す（「元に戻す」で星が戻ったときに記録も戻るように）。

## 3-3. 変更したときの決まり（データを壊さないために）

| 操作 | 影響 |
|---|---|
| 星の名前を変える | リンクはIDなので切れない。表示だけ変わる |
| 星を削除する | その星への**リンクは残り**、星は「まだ知らない星」に戻る（中身は消える） |
| | その星の記述と、その星の**意味のつながり**は削除する |
| | 出典は残る |
| | 削除の前に、影響を一覧で見せる。例：「記述3件、意味のつながり2本が消えます。この星へのリンク5件は残ります」 |
| | 削除した直後の数秒間、「**元に戻す**」を出す。押すと削除前の状態に完全に戻る |
| 記述を削除する | その記述からの言及のつながりが消える |
| | どこからもリンクされず、中身もない「まだ知らない星」は、自動で消える |
| 出典を削除する | 使っている記述があれば、その一覧を見せてから削除する。各記述の確認状態は上の決まりで戻る |
| 同じ名前の星を作ろうとする | 既存の星（別名を含む）を見つけたら、「この星ではありませんか？」と知らせる |
| | 「まだ知らない星」と同じ名前なら、その星を登録済みにする（新しく作らない） |

## 3-4. 星にたどり着く道（どこからでも星に行ける）

| 入口 | 例 |
|---|---|
| 宇宙で星をタップ | 眺めていて気になった星 |
| 記述の中のリンク | Wikipedia型の寄り道（N6） |
| 星の「関連する知識」一覧 | 意味のつながりをたどる |
| 検索 | 名前・別名・記述・出典で探す |
| 「まだ知らない星」一覧 | 次に調べること |
| 「未確認の事実」一覧 | ファクトチェックの続き |
| たどった道のり（履歴） | さっき見た星に戻る |
| アドレス | ブックマークや共有したリンクから直接開く |

# B. 操作の構造

## 3-5. 場所（ユーザーがいる状態）

画面の配置ではなく、「今どこにいるか」の一覧。

| 場所 | ここでできること |
|---|---|
| **宇宙** | 眺める、回す、星を選ぶ。すべての出発点 |
| **星のプレビュー** | 選んだ星の名前・概要・確かさを、宇宙を見ながら確認する |
| **星のページ** | 記述・出典・関連する知識を全部読む。リンクから次の星へ |
| **記述の編集** | 記述を書く、事実か意見かを選ぶ、リンクを付ける |
| **出典の選択・追加** | 既存の出典を選ぶ、新しく登録する、外部検索で調べる |
| **つながりの作成** | 2つの星を結ぶ、種類と理由を決める |
| **探す** | 検索と絞り込み |
| **リスト** | 「まだ知らない星」「未確認の事実」の一覧 |
| **設定・データ** | バックアップ・復元・表示の設定 |

宇宙の中には、操作の状態（モード）がある。

| モード | 内容 |
|---|---|
| 通常 | 眺める・選ぶ |
| 移動 | 星を動かす（プロトタイプで実装済み） |
| 接続 | 2つ目の星を選んでつなぐ（プロトタイプで実装済み） |

## 3-6. 主な流れ

### 流れ1：たどる（寄り道）— N6, N1

```
宇宙 ─タップ→ 星のプレビュー ─開く→ 星のページ
                                    │
                         記述の中の[[プラトン]]を押す
                                    ▼
             宇宙の視点がプラトンへ飛ぶ ＋ プラトンのページになる
                                    │
                  （何度でも繰り返せる。道のりが記録される）
                                    ▼
             「戻る」で一つ前の星へ（視点も戻る）
```

- リンク先が「まだ知らない星」の場合は、「この星を調べて登録する」を案内する（流れ4へ）。
- 道のりは、**宇宙の中にも光の軌跡として残す**（見せ方は表層で決める）。

### 流れ2：登録する — N4

```
追加 → 名前を入力
        ├─ 既存の星と一致 → 「この星ではありませんか？」→ その星を開く
        ├─ まだ知らない星と一致 → その星を登録済みにして続ける
        └─ 新しい名前 → 続ける
     → 種類・カテゴリー・概要
     → 記述を追加（事実／意見を選ぶ）
        → 本文を書く → リンクの候補が自動で提案される → 採用するものを選ぶ
        → 事実なら：出典を付ける（任意。付けなければ「未確認」）
     → 保存 → 宇宙に星が現れ、視点がその星へ向く
```

- 一度に完璧にしなくてよい。名前だけ・記述1つだけでも保存できる。
  - 後から足せるようにし、登録の気軽さを守る。

### 流れ3：ファクトチェックする — N4

```
事実の記述 → 「調べる」→ 外部検索（Google／Wikipedia／Google Scholar）が開く
          → 資料を読む → アプリに戻る
          → 出典を追加（URL・タイトル）
          → 内容が一致した → 「確認済み」にする＋確認メモ
          → 食い違っていた → 「異論あり」にする＋理由のメモ
             （必要なら記述を書き直す → 状態は「出典あり」に戻る）
```

### 流れ4：まだ知らない星を調べる — N6

```
薄い星をタップ（または「まだ知らない星」一覧から選ぶ）
 → どの星のどの記述からリンクされているかを見る（文脈）
 → 「調べる」で外部検索
 → 「登録する」→ 流れ2（名前は入力済み）
```

### 流れ5：つなぐ — N1

```
星のページ → 「つなぐ」→ 相手の星を選ぶ（宇宙でタップ／一覧／検索）
 → 種類を選ぶ → 理由を書く（事実／意見）→ 事実なら出典
 → 保存 → 宇宙に線が現れる
```

### 流れ6：探す — N5

```
探す → 言葉を入力（または絞り込み：カテゴリー・種類・確認状態）
 → 結果を選ぶ → 宇宙の視点がその星へ飛び、プレビューが開く
```

### 流れ7：データを守る — 原則6

```
設定・データ → 書き出す → JSONファイルが保存される
設定・データ → 読み込む → 中身の確認（星の数など）→ 上書きの確認 → 復元
```

## 3-7. 振る舞いの原則（すべての操作に共通）

1. **視点は知識についていく**
   - 別の星に移動したら、宇宙の視点もその星へ滑らかに動く。
   - 読むことと、宇宙で見ることを常に一致させる。
2. **いつでも戻れる**
   - たどった道のりは「戻る」で戻れる。宇宙を回しても迷子にならない。
3. **すぐ保存、すぐ反映**
   - 保存ボタンを押し忘れて内容が消えることがないようにする。
   - 入力中の内容は、画面を閉じても下書きとして残す。
4. **消す前に影響を見せ、消した後も戻せる**
   - 削除はいきなり行わない。何が消え、何が残るかを先に見せる。
   - 削除した直後の数秒間は「元に戻す」を出す。
5. **確かさを常に見せる**
   - 記述・星・つながりのどこを見ても、事実か意見か、確認状態がわかる。
6. **オフラインでも使える**
   - 外部検索以外のすべての操作は、ネットにつながっていなくてもできる。
7. **エラーを隠さない**
   - 保存の失敗などは、必ず画面で知らせる。
