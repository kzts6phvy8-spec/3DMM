# 第1層：戦略（Strategy）

状態：**草案**（「未確定」の項目は利用者の回答待ち）

戦略の層では、2つの問いに答える。

- **ユーザーニーズ**：使う人は何に困っていて、何を得たいのか
- **プロダクトの目的**：このプロダクトは何を実現するために存在するのか

---

## 1-1. 一言で言うと

> **自分が学んだすべての知識を一つの宇宙として眺め、つながりから新しい発見を生む場所。**

## 1-2. マインドマップとの違い（出発点の再定義）

トニー・ブザンのマインドマップから出発するが、構造の前提が違う。

| | マインドマップ（ブザン） | Knowledge Cosmos |
|---|---|---|
| 中心 | 1つのテーマが中心にある | 中心がない。どの知識も中心になりうる |
| 形 | 放射状の木構造（親→子） | 網の目（ネットワーク） |
| 範囲 | 1枚＝1テーマ | 1つの宇宙＝自分の知識すべて |
| つながり | 枝分かれのみ。枝どうしは基本つながらない | 分野をまたいで自由につながる |
| 線の意味 | 「下位にある」だけ | 因果・類似・対立など、つながりの**意味**を持つ |
| 使う時 | 考えを広げる・整理する（一時的） | 知識を蓄積し、探索し、再発見する（継続的） |

マインドマップから受け継ぐもの：

- 視覚で考えること
- 放射的な連想
- 色や大きさで重要度を表すこと

捨てるもの：

- 単一の中心
- 木構造という制約

## 1-3. ユーザー

- **初期ユーザー**：自分自身（1人）
- **主な端末**：iPhone（まずWeb版、後でアプリ化）
- **ユーザー像の詳細**：**未確定**（「私について」の情報を受けて記入する）

## 1-4. ユーザーニーズ（解決したいこと）

仮説として、次の4つを置く。

1. **散らばる**：学んだ知識が本・メモ・記憶にバラバラに散らばっていて、全体が見えない
2. **つながらない**：別の分野で学んだことが、実はつながっていることに気づけない
3. **忘れる**：一度学んだことを思い出す仕組みがない
4. **楽しくない**：整理作業が義務になり、続かない

この中で最も重要なのはどれか：**未確定**

## 1-5. プロダクトの目的

1. **可視化**：自分の知識の全体像と、つながりを見えるようにする
2. **発見**：思いがけない関連性に気づき、新しい興味や考えが生まれる
3. **蓄積の喜び**：知識を自分の手で星として置く行為そのものを楽しめる

長期的な目的としては、価値が確認できた後に一般公開や収益化を検討する。ただし今は追わない。

## 1-6. 守る原則（戦略レベルの判断基準）

迷ったときは、この順で優先する。

1. **自分の手で登録する楽しさを奪わない**：AIは提案するだけで、確定は人がする
2. **意味のあるつながり**：線を引くだけでなく、「なぜつながるか」を残す
3. **iPhoneで片手でも気持ちよく使える**
4. **データは自分のもの**：端末内に保存し、いつでもJSONで持ち出せる
5. **事実と未確認を区別する**：出典のない情報はそうとわかるようにする

## 1-7. 成功の定義（どうなったら「価値がある」と言えるか）

1か月使った時点で、次を満たしていれば成功とする（数値は仮）。

- 週に3日以上、自分から開いている
- 知識が50個以上登録されている
- **異なるカテゴリー間のつながり**が10本以上ある（＝「発見」の指標）
- 「これとこれがつながるのか」と感じた体験が実際にあった（主観で振り返る）

## 1-8. やらないこと（戦略上の境界）

- 汎用のメモアプリやノートアプリにはしない（文章を長く書く場所ではない）
- タスク管理やスケジュールの機能は持たない
- 当面は、他人との共有・SNS的な要素を作らない
- AIに知識を自動で整理させない

## 1-9. プラットフォーム戦略

- Web版を先に完成させ、価値を検証する
- 価値が確認できたらアプリに翻訳する
- 戦略・要件・構造の3層は、両方で共通にする

## 確認したいこと（この層を確定するため）

1. **どんな知識を入れるか**
   - 例：読書／仕事の専門知識／学校の勉強／趣味／ニュース／雑学 など
2. **いつ使うか**
   - 例：学んだ直後に登録する／週末にまとめて眺める／何かを考えるときに探索する
3. **「発見」とは、あなたにとってどんな体験か**
   - 例：分野の違う知識がつながる／忘れていた知識を再会する／次に学ぶことが見つかる
4. **1-4の4つのニーズのうち、一番強いのはどれか**
5. **「私について」の情報**（1-3に反映する）
