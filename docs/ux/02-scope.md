## 2-1. 一番大きな変更点：「星」は百科事典の1項目になる

最初の企画書では、1つの星に「説明」が1つ、「出典URL」が1つ付くだけだった。
戦略で決まった次の3点を満たすには、これでは足りない。

- 本当かどうかを徹底して確認する（N4）
- 事実と意見を分ける（原則2）
- 言葉から言葉へたどる（N6）

そこで、**Wikipediaと同じ形**にする。

```
星（項目）  例：「ソクラテス」
 ├─ 概要（一文の要約）
 ├─ 記述1：［事実］ソクラテスは古代アテナイの哲学者である。   ← 出典：A、B ／ 確認済み
 ├─ 記述2：［事実］著作を残さなかった。                       ← 出典：C ／ 出典あり
 ├─ 記述3：［事実］[[プラトン]]は彼の弟子である。             ← 出典：A ／ 確認済み
 └─ 記述4：［意見］[[無知の知]]は現代の[[科学的懐疑]]に通じる。 ← 自分の考え
```

- 本当かどうかの確認は、**星ごとではなく「記述（1つの文）」ごと**に行う。
  - 1つの星の中に、確かな事実と怪しい情報が混ざることがあるため。
- `[[ ]]` で囲んだ言葉は、**別の星へのリンク**になる。

## 2-2. コンテンツ要件（何を入れるか）

### C1. 星（項目） — N1, N3, N6

1つの言葉・概念・人物・出来事・場所・作品などを表す。

| 持つもの | 説明 |
|---|---|
| 名前 | 項目の名前（例：ソクラテス）。同じ名前で別のものは補足を付ける（例：マーキュリー（惑星）） |
| Wikipediaの記事名 | 任意。名前で見つからないとき、候補から選んだ記事を覚えておく（例：『国家』→ 国家 (対話篇)） |
| 別名 | 表記ゆれや別の呼び方（例：Socrates）。リンクの自動検出に使う |
| 種類 | 人物／概念／出来事／場所／作品／用語／その他 |
| カテゴリー | 分野（例：哲学、歴史）。色分けに使う |
| 概要 | 一文の要約。星をタップしたとき最初に見える |
| 記述 | 事実・意見の文のリスト（C2） |
| ~~重要度~~ | 画面からは廃止（利用者の判断、2026-11-13）。星の大きさの内部値としてだけ残す |
| 登録日時・更新日時 | |
| 3D空間での位置 | |

### C2. 記述（1つの文） — N4

| 持つもの | 説明 |
|---|---|
| 本文 | 1つの文。`[[言葉]]` でリンクを含められる |
| 話題 | 任意。語源・定義・歴史・人物・数値など（第3層で追加） |
| 区分 | **事実** か **意見** か |
| 出典 | 0個以上（C3）。事実にのみ付ける |

**確認状態（事実の記述のみ）** ※2026-11-13に廃止。以下は当時の記録

| 状態 | 意味 | 決め方 |
|---|---|---|
| 未確認 | 出典がまだない | 出典が0個のとき自動 |
| 出典あり | 出典はあるが、まだ自分で確かめていない | 出典が1個以上のとき自動 |
| 確認済み | 信頼できる出典を1つ以上**自分で読み**、記述と内容が一致することを確かめた | **自分で付ける** |
| 異論あり | 出典どうしが食い違う、または反対の根拠がある | **自分で付ける**。理由をメモに残す |

- 「確認済み」と「異論あり」は、人が判断して付ける。
- AIや自動処理が付けることは**禁止**。

**意見**は「自分の考え」として、見た目で事実と区別する（「意見」の札・点線）。

**事実と意見の線引き**

- 事実：出典で確かめられること。
- 他人の主張は**事実**として扱う。
  - 例：「〇〇は△△と主張した」
  - 主張したこと自体は、出典で確かめられるため。
- 意見：**自分の考えだけ**。

### C3. 出典 — N4

| 持つもの | 説明 |
|---|---|
| 種類 | Webページ／書籍／論文／その他 |
| タイトル | 必須 |
| URL | Webの場合 |
| 著者・発行元 | 任意 |
| 書籍のページ | 任意 |
| 確認した日 | 自動で記録 |

1つの出典を、複数の記述で使い回せるようにする。
例：同じ本を何度も入力しなくてよい。

### C4. つながり（星と星を結ぶ線） — N1, N2

つながりは2種類に分ける。

| 種類 | どうできるか | 意味 |
|---|---|---|
| **言及のつながり** | 記述の中で `[[別の星]]` にリンクすると、**自動で**できる | 「説明の中で触れている」という弱いつながり |
| **意味のつながり** | 自分で線を引いて作る（今のプロトタイプの「つなぐ」） | 因果・類似・対立などの種類と、理由を持つ強いつながり |

意味のつながりの「理由」も、事実か意見かを区別する。

- **事実**の場合：出典を付けられる
  - 例：「プラトンはソクラテスの弟子」
- **意見**の場合：自分の発見として表示する
  - 例：「無知の知と科学的懐疑は似ている」

### C5. まだ知らない星 — N6

`[[言葉]]` でリンクしたのに、まだ項目がない言葉。

- 宇宙の中に**薄い光の星**として現れる（Wikipediaの「赤いリンク」と同じ考え方）。
- タップすると「この星について調べて登録する」ができる。
- 「次に知りたいことリスト」として一覧で見られる。

### C6. 初期の知識セット — N5, N6（確定後に追加）

最初から寄り道やつながりを楽しめるように、あらかじめ星をある程度入れておく（利用者の提案）。

**作り方の決まり**（戦略の原則2「ファクトチェック」を守るため）

- Claude（AI）が用意する。
- 事実の記述には、必ず出典を付ける（例：百科事典やWikipediaの該当ページ）。
- 状態は最高でも「**出典あり**」にする。「確認済み」には**しない**。
  - 確認済みにするのは、あなたが自分で出典を読んだときだけ（決めたこと①）。
  - つまり初期セットは、そのまま**ファクトチェックの練習帳**にもなる。
- 初期セットの星には「初期セット」の印を付ける。不要なら**まとめて削除**できる。
- 星どうしを `[[リンク]]` でたくさん結び、「まだ知らない星」も適度に残す。
  - 最初から寄り道ができ、次に調べることも見つかる状態にする。
- 入れる時期：R1のデータの形（記述・出典・確認状態）ができてから。今の形で入れると、後で作り直しになるため。
- 量と分野：**約100個、幅広い分野**（哲学・歴史・科学・宇宙・生物・芸術・言語・経済など）。分野をまたぐリンクを多めにする。
- 追加：第2弾（約75個）で、第1弾の「まだ知らない星」の多くを登録済みにした。初期セットは今後も段階的に増やす（版を上げると、既存の端末にも足りない分だけ1回補われる）。
- 追加：第3弾（約900個）は、Wikipedia「すべての言語版にあるべき項目の一覧」（約1000項目）から作る。記述は各記事の冒頭の文をWikipediaのまま使う（`scripts/build_vital.py`）。Wikipedia全体（約140万項目）は、容量・表示・取得制限の理由で最初からは入れない（利用者と合意）。
- 追加（2026-11-13）：第4弾（約8,700個）は、同じ一覧の「1万の項目」版から、第1〜3弾にない項目を同じ決まりで作る（`scripts/build_vital10k.py`）。利用者の「星が全然足りない」という要望による。全部で約9,800個。すでに使っている端末には、起動時に1回だけ追加する（自分で作った星・記述は消さない）。

## 2-3. 機能要件（何ができるか）

### F1. 宇宙を眺める — N1, N3, N5

- 3D空間で星とつながりを眺める（回転・ズーム・移動）
- 星をタップすると、概要が出る
- 線の種類で見た目を変える
  - 言及のつながり：細い
  - 意味のつながり：明るい
  - 意見のつながり：点線
- 星の確認状態がわかる
  - 例：確認済みが多い星ほど、はっきり光る

### F2. 項目を読む・たどる（Wikipedia型の体験） — N6, N2

- 星の詳細で、記述の一覧を読む
- 記述の中のリンクを押すと、**その星へ移動**する
  - 宇宙の視点もその星へ飛ぶ
- **たどった道のりが残る**
  - 例：ソクラテス → プラトン → イデア論
  - 「戻る」で前の星に戻れる
- 事実と意見、確認状態がひと目でわかる
- 出典を押すと、出典の詳細やWebページが開く

### F3. 知識を登録・編集する — N4

- 星を追加・編集・削除する
- 記述を追加・編集・削除する（事実か意見かを選ぶ）
- 出典を追加する。既に登録した出典からも選べる
- 確認状態を変更し、確認メモを書く
- リンクの付け方
  - **自動検出**：記述の中に、既にある星の名前や別名があれば「リンクにしますか？」と提案する。確定は人がする。
  - **手動**：言葉を選んでリンクにする。まだない言葉なら「まだ知らない星」になる。
  - iPhoneで `[[ ]]` を打つのは大変なので、ボタン操作でできるようにする。
- **ファクトチェックの補助（外部検索）**
  - 記述の横の「調べる」ボタンを押すと、その文を外部サイトで検索する。
  - 検索先：Google／Wikipedia／Google Scholar（論文）
  - アプリは検索ページを**開くだけ**。検索エンジンを組み込まないので、サーバーや費用は不要。
  - 見つけた出典を、そのまま記述に追加できる。
  - 検索結果をアプリの中に直接表示する機能は、R2で検討する（サーバーと検索APIが必要なため）。
- 星の削除時の扱い
  - その星へのリンクは「まだ知らない星」に戻る。
  - 意味のつながりは一緒に削除する。
  - 削除の前に、影響を受けるものを表示する。

### F4. つなぐ — N1

- 2つの星を意味のつながりで結ぶ（種類・理由・事実か意見か）
- 相手の星は、宇宙でタップするか、**名前で検索**して選ぶ（プロトタイプで実装済み）
  - 星が増えても探せるように、一覧ではなく検索にする（利用者の提案）
  - ひらがな・カタカナ・半角の違いは区別しない

### F5. 発見を差し出す（開いたときの出会い） — N5, N2, N1

アプリを開いたとき、宇宙の上に**小さなカードを1枚**出す。これを「今日の発見」と呼ぶ。
カードを押すと、その発見に関係する星へ視点が飛ぶ。

例（知識が十分にたまった後のイメージ）：

```
┌──────────────────────────────┐
│ 今日の発見                     │
│ 「ソクラテス」と「量子力学」は  │
│  3歩でつながっています          │
│ ソクラテス → 無知の知 →        │
│   科学的懐疑 → 量子力学         │
│                     [たどる →] │
└──────────────────────────────┘
```

候補は次のとおり。どれを作るかは、R1を実際に使い、知識がたまってから決める（決めたいこと④）。

- **遠いつながり**：違うカテゴリーの星が、何本かの線を経てつながっている道を見せる
  - 例：「哲学 → … → 物理学 は、3歩でつながっています」
- **再会**：しばらく見ていない星を1つ見せる
- **まだ知らない星**：リンクだけされている、まだ調べていない言葉を1つ見せる
- **未確認の事実**：出典がない、または確認していない記述を1つ見せる（ファクトチェックのきっかけ）

### F6. 探す — N5

- 名前・別名・記述・出典で検索する
- カテゴリー・種類・確認状態で絞り込む
  - 例：「未確認の事実だけ」
- 検索結果を押すと、その星へ移動する

### F7. データを守る — 原則6

- すべて端末内に保存する
- JSONで書き出す・読み込む（バックアップと復元）
- 読み込みで上書きする前には確認を出す

### F8. 自由に配置する — N1

- 星をドラッグで動かし、位置を保存する（プロトタイプで実装済み）

### F12. 関わり方の記録 — N1, N5（2026-11-13に追加）

「登録済みかどうか」とは別に、自分がその星とどう関わってきたかを星ごとに記録する。
理由：初期セットは全員同じなので、「登録済み」だけでは人による違いが出ない。光っていない星でも、知らないとは限らない。

- 記録するもの：星を開いた回数・はじめて開いた日・最後に開いた日・月ごとの回数
- 今あるデータから数えるもの：自分で加えた記述の数、自分で結んだつながりの数、🌱で広げた言葉の数、自分で加えた星かどうか
- 星のページの「あなたとこの星」で見られる
- 今後の土台：今月の発見レポート、友達の宇宙と重ねる

### F13. 今月の発見レポート — N1, N5（2026-11-13に追加）

その月に宇宙がどう育ったかを振り返る。入口は「その他」→「📅 今月の発見」。前の月にも戻れる。

- 星の数（月の初め → 月の終わり）
- 加えた星・加えた記述・結んだつながり・開いた星の数
- 新しくつながった分野の組み合わせ（意味のつながりと、記述の中のリンクの両方から。その月より前に結ばれていない組み合わせだけ）
- よく開いた星（上位5つ）
- 決まり：今あるデータから数える（消したものは含まない）。初期セットは「最初からあったもの」として数え、入れた月の発見には含めない。

### F14. 毎日のつながりパズル — N1, N2（2026-11-13に追加）

日付で決まるスタートとゴールの星を、つながりをたどって結ぶ。入口は「その他」→「🧩 今日のつながりパズル」。

- 使うのは初期セットの星と、初期セットの記述のリンク・つながりだけ。同じ日・同じ版なら誰でも同じ問題になる（サーバー不要）。
- 最短は3〜5手。スタートとゴールは、できるだけ分野が違う星にする。
- 「1手戻る」も1手と数える（やり直しで最短にできないように）。
- ギブアップすると最短の道のりを見せる。
- 結果のシェア：日付・スタート→ゴール・手数・絵文字。途中の星は出さない（答えのネタばれ防止）。
- その日の途中経過は端末のブラウザに保存する。
- 注意：初期セットの版が違う、または初期セットの記述を消した場合は、問題が変わることがある。

### F15. 友達の宇宙と重ねる — N1, N2（2026-11-13に追加）

「宇宙カード」を送り合って、2人が関わった星を比べる。入口は「その他」→「👥 友達の宇宙と重ねる」。サーバーは使わない。

- 宇宙カードに入るもの：関わった星の名前・分野・深さ、自分の名前（任意）。記述・出典などの中身は入れない。
- 深さ：「開いた」（開いたことがある）／「深く関わった」（記述を加えた・つないだ・広げた・自分で作った）。
  - 初期セットは全員同じなので、「持っているか」ではなく「関わったか」で比べる（F12の記録を使う）。
- 星は名前で合わせる（ひらがな／カタカナ・全角／半角の違いは吸収）。
- 見せるもの：重なり度（共通 ÷ どちらかが関わった星）、共通／友達だけ／自分だけの一覧。
- 「宇宙で重ねて見る」：共通＝金、友達だけ＝桃、自分だけ＝青で光らせ、ほかの星は暗くする。今のデータから毎回計算する。
- 友達だけの星が自分の宇宙にないときは、「＋ 星にする」で新しい星として追加できる。
- 友達のカードは端末のブラウザに残る（「友達のカードを消す」で消せる）。

### F16. 言葉クイズ（星の種を見つける） — N5, N6（2026-11-13に追加）

みんなが知らなさそうな、でも面白い言葉の意味を4択で当てる。気になった言葉は、そのまま星にできる。入口は「その他」→「❓ 言葉クイズ」。

- ねらい：初期セットは全員同じなので、各自が星を増やすきっかけにする（利用者のアイデア）。
- 無料は1日10問まで（日付で決まる）。有料プランでは「もっと解く」で続けられる（2026-11-13に利用者が決定）。
  - 課金の仕組みはまだない。`src/lib/plan.ts` の `hasUnlimitedQuiz()` が有料かどうかを返す入口で、今は常に無料。見た目だけの課金ボタンは作らない。
- 答えた言葉と、宇宙ですでに登録済みの言葉は出さない。
- 選択肢は、問題の言葉リストにある別の言葉の**本当の説明**（Wikipediaの冒頭の文）から作る。うその説明は作らない。できるだけ同じ分野の言葉から選ぶ。
- 説明の中の言葉そのもの・名前の一部・学名は「〇〇」に伏せる（答えのヒントにならないように）。
- 答えたあと：各選択肢がどの言葉の説明かを見せる。出典（Wikipedia）を示す。
- 「✦ 星にする」：Wikipediaの冒頭の文（最大3文）を記述として、出典つきで星を作る。
- 言葉リスト：`src/data/quizWords.json`（`scripts/build_quiz.py` で作る）。記事がない言葉・曖昧さ回避・別の話題に転送される言葉・よく知られた言葉は外す。
- 2026-11-14：言葉を130語から615語に増やした（利用者の要望）。初期セットの星（約9,800個）と同じ言葉は入れない。名前の中の特徴的な漢字（地名・人名など）も説明の中で伏せる。説明になっていない文・前の文に頼る文・別の意味の記事は外す（理由は `scripts/build_quiz.py` の EXCLUDE）。

### F17. 毎日の連続記録 — N1, N5（2026-11-14に追加）

Duolingoのように、毎日続けた日数を数えて見せる（利用者の要望）。

- その日やったと数える条件：言葉クイズに1問答える、またはつながりパズルでゴールする（ギブアップは数えない）（利用者が決定）。
- 見せ方：起動したときにカードで知らせる。1日に1回だけ（利用者が決定）。
  - 続いている：「🔥 〇日連続」。今日まだなら「今日も解くと〇日になります」。
  - 途切れた：「記録が途切れました」と、これまでの最高を見せる。
  - まだ記録がない：連続記録の説明を見せる。
  - 今日まだなら、「言葉クイズ」「つながりパズル」へすぐ行けるボタンを出す。
- 今日まだやっていなくても、昨日まで続いていれば、その日数を「続いている」と数える（その日のうちにやれば途切れない）。
- 日付は端末の時計の日付で決める。

### F18. 端末の同期（有料プラン） — N3（2026-11-14に追加）

iPhoneとPCなど、ほかの端末と同じ宇宙を使えるようにする（利用者の要望。有料プランの機能にすると利用者が決定）。

- 預け先：Supabase（利用者が選択）。表と決まりは `supabase/schema.sql`。
- ログイン：メールアドレスとパスワード。入口は「その他」→「端末の同期（有料プラン）」。
- 有料かどうか：Supabase の表 `profiles` の `plan`（free／paid）。
  - 支払いの仕組みはまだない。それまでは、管理者（利用者）が管理画面で paid にした人だけ使える（2026-11-14に決定）。
  - 本人は自分のプランを読めるだけで、書き換えられない。同期データも、有料の本人しか読み書きできない（RLS）。
- 預けるもの：宇宙のデータ全体（星・記述・出典・つながり・関わり方の記録・連続記録）を圧縮して1人1行。
- そろえ方：
  - ほかの端末だけが変わった → 自動でこの端末をそろえる（「元に戻す」は出さない。元に戻すと、次の同期でほかの端末の変更を古いデータで上書きしてしまうため）。
  - この端末だけが変わった → 自動で預ける（変更から20秒後・アプリを閉じるとき・「今すぐ同期」）。
  - 両方で変わった／初めての同期で、この端末にも自分で作ったものがある → どちらを残すか聞く。「保存されているデータにする」を選んだときは、直後に「元に戻す」ができる。「あとで決める」もできる。
  - 初めての同期で、この端末に自分で作ったものがない → 聞かずに保存されているほうにそろえる。
- 関わり方の記録・連続記録は、そろえるとき足し合わせる（消さない）。
- 編集は、ログインしていなくても、無料でも、これまでどおり端末の中でできる。

### F11. ほかの辞書で探す — N4, N6

- 日本語版Wikipediaに載っていない言葉や、語源を知りたい言葉のために、次の辞書から記述の候補を選んで追加できる（AIは使わない）。
  - 英語版Wikipedia（冒頭の文）
  - ウィクショナリー（日本語版・英語版。語源・意味などの節）
- 出典は「Wikipedia（英語版）：記事名」「ウィクショナリー：見出し語」などとして自動で付く。
- 英語の文は英語のまま登録する（翻訳はしない）。

### F10. 🌱 広げる（星の種まき） — N6

- 星のページの「🌱 Wikipediaのリンクから広げる」を押すと、その星のWikipedia記事に出てくる言葉を、まだ知らない星として周りに生やす（1回に10個、押すたびに次の言葉）。
- 冒頭の文に出てくる言葉を優先する。年・日付・数字だけの言葉は除く。
- 生えた星は、もとの星が登録済みで残っている間は残る。もとの星を消すと一緒に消える（元に戻せる）。
- これにより、宇宙は興味のあるところからWikipedia全体へ広げられる。

### F9. Wikipediaから取り込む — N6, N5（確定後に追加）

「この世のすべての言葉」とつながる宇宙に近づけるため（利用者の希望）。

- 「まだ知らない星」を開くと、Wikipedia（日本語版）からその言葉の概要を**その場で取ってきて表示**する。
  - ネットにつながっているときのみ。
- 気に入ったら「自分の宇宙に登録」できる。
- 取り込んだ内容の扱い
  - 出典として「Wikipedia：記事名」を自動で付ける。
  - 状態は「**出典あり**」まで。確認済みにはしない。
- 3D空間に表示するのは、登録した星と、そこからリンクされた「まだ知らない星」だけ。Wikipediaの全項目は表示しない。
- Wikipediaの文章の利用条件（CC BY-SA）に従い、出典を必ず表示する。
  - 一般公開するときは、利用条件をもう一度確認する。
- 実装はブラウザから直接Wikipediaの公開APIを呼ぶ。サーバーやAPIキーは不要。
- 時期：R1。データの形と初期セットの後に作る。

## 2-4. やらないこと（要件の境界）

- AIによる自動の確定はしない
  - 確認状態・リンク・つながりは、すべて人が確定する。
- 記述の長文化はしない
  - 1つの記述は1つの文を基本とする。長い文章はメモアプリの役割。
- 画像・動画の添付はしない（当面）
- 他人との共有・コメント・いいねはしない（当面）
- ~~複数端末の同期はしない（当面）~~ → 2026-11-14、有料プランの機能として追加（F18）
- ~~ログイン・会員登録はしない（当面）~~ → 2026-11-14、同期のためにメールアドレスでのログインを追加（F18）。ログインしなくても、ほかの機能はすべて使える

## 2-5. 優先順位（何から作るか）

| 段階 | 内容 | ねらい |
|---|---|---|
| **R1：Web版の土台** | C1〜C5、F1〜F4、F6〜F8 | 事実を確かめながら登録し、たどり、つなぐ体験が一通りできる |
| **R2：発見とAI補助** | F5（今日の発見）を本格的に作る | 開くたびに出会いがある |
| | AI補助：記述の抽出、出典候補の提示、反対の根拠の提示（すべて提案のみ） | 登録とファクトチェックの手間を減らす |
| | 集中モード（選んだ星の周りだけを表示） | 星が増えても見やすくする |
| **R3：アプリ化** | Web版の骨格・表層をアプリに翻訳する | 価値が確認できたら |

AI補助をR2にする理由は2つある。

- ファクトチェックの手順を、まず人の手で固めてから自動化したいため。
- APIキーを安全に扱うサーバーが必要になるため。

## 2-6. 今のプロトタイプとの差（参考）

| | プロトタイプ | 要件 |

| 星の中身 | 説明1つ＋出典URL1つ | 概要＋記述のリスト（文ごとに事実／意見・出典・確認状態） |
