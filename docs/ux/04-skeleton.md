# 第4層：骨格（Skeleton）— Web版

状態：**確定**

> **変更（2026-11-13）**：ファクトチェック機能（確認状態：未確認／出典あり／確認済み／異論あり）はなくした。
> 残すもの：**出典の表示**、外部検索の「調べる」ボタン、**事実と意見の区別**。
> この文書の中に残る「確認状態」に関する記述は、当時の記録として読む（実装はしない）。


骨格の層では、構造（[03-structure.md](./03-structure.md)）で決めた「場所」と「流れ」を、画面の上に配置する。次の3つを決める。

- **画面の配置**（インターフェース設計）：ボタンや入力欄をどこに置くか
- **移動のしかた**（ナビゲーション設計）：場所から場所へどう移るか
- **情報の見せ方**（情報設計）：何をどの順で、どの強さで見せるか

色・光・質感などの見た目は、次の表層（第5層）で決める。図は配置を示すだけで、見た目ではない。

---

## 4-0. 前提

- 対象は **iPhoneの縦画面**。基準の大きさは幅390×高さ844（iPhone 13〜15）。
- **片手で使える**ことを重視する。
  - 親指が届きやすいのは画面の下半分。
  - よく使う操作は下に、たまに使う操作は上に置く。
- 押せる部品は、**縦横44px以上**にする。
- 画面の主役は、いつも**宇宙**。ほかの部品は宇宙の上に重ねて表示し、宇宙を隠しすぎない。
- PC（横長の画面）では、シートを右側のパネルにする。

## 4-1. 画面の全体構成（ゾーン）

```
┌──────────────────────────┐
│ ① 上部バー                 │  タイトル・星の数
│                          │
│                          │
│      ② 宇宙（全面）         │  眺める・回す・星を選ぶ
│                          │
│                          │
│ ③ シート（必要なときだけ）   │  プレビュー／ページ／まだ知らない星
├──────────────────────────┤
│ ④ 下部バー（主な操作）      │  探す・リスト・＋追加・メニュー
└──────────────────────────┘
```

| ゾーン | 置くもの | 理由 |
|---|---|---|
| ① 上部バー | アプリ名、星・つながり・未知の数 | 見るだけの情報なので、指が届きにくい上でよい |
| ② 宇宙 | 星・線・名前 | 主役。画面の全面を使う |
| ③ シート | 星のプレビュー／ページ | 下から出す。宇宙を見ながら読める |
| ④ 下部バー | よく使う操作 | 親指が届く位置 |

**④ 下部バーは新しい案**（決めたいこと①）。
今は「＋追加」と「⋯メニュー」が上部にあり、「探す」と「リスト」の置き場所がまだない。

## 4-2. 移動のしかた（ナビゲーション）

### 全体の移動（どこからでも使える）

下部バーに4つ並べる（案）。

```
┌───────┬───────┬───────┬───────┐
│ 🔍探す │ ☰リスト│ ＋追加 │ ⋯その他│
└───────┴───────┴───────┴───────┘
```

| ボタン | 行き先 | 構造の場所 |
|---|---|---|
| 🔍 探す | 検索画面 | 探す（流れ6） |
| ☰ リスト | まだ知らない星／未確認の事実／異論あり の一覧 | リスト |
| ＋ 追加 | 星の追加フォーム | 流れ2 |
| ⋯ その他 | バックアップ・復元、初期セット、表示の設定 | 設定・データ（流れ7） |

### 星から星への移動（寄り道）

- 記述の中のリンク、関連する知識、つながりの候補、この星が出てくる記述 → その星へ
  - 視点も一緒に動く（構造の原則1）。
- **たどった道のり**をシートの上部に表示する。
  - 例：`ソクラテス › プラトン › イデア論`
  - どれかを押すと、そこまで戻れる。
  - 今は「‹」1つで1歩ずつ戻るだけなので、それを広げる案。
- 宇宙の何もないところをタップ → シートを閉じる。

### 一時的な移動（モード）

- 移動モード・接続モードのときは、下部バーの代わりに**モードの案内**を出す。
  - 内容：説明と、「完了」または「やめる」ボタン。
- 接続モードの検索欄は、キーボードで隠れないよう**画面上部**に出す（実装済み）。

## 4-3. 各場所の配置

### A. 宇宙（通常）

```
┌──────────────────────────┐
│ Knowledge Cosmos          │
│ 星99・つながり20・未知54     │
│                          │
│     ・  ソクラテス           │
│   ・    ・  プラトン         │  遠くからは重要な星の名前だけ
│       ・      ・           │  近づくほど名前が増える
│                          │
├──────────────────────────┤
│ 🔍探す  ☰リスト  ＋追加  ⋯  │
└──────────────────────────┘
```

### B. 星のプレビュー（星をタップ）

シートの高さは画面の**約4割**。宇宙は上側に残り、選んだ星はシートに隠れない位置にずれる（実装済み）。

```
├──────────────────────────┤
│ ━━                       │  つまみ（上に引くとページへ）
│ ‹ ソクラテス › プラトン      │  道のり（寄り道したときだけ）
│ ● プラトン            ×   │  名前・閉じる
│   人物・哲学・事実4件中確認済み0│  種類・分野・確かさ
│ ソクラテスの弟子で…          │  概要
│ ┌ ✦ 雑学 ───────────┐    │
│ │「プラトン」は本名ではなく…  │    │  雑学（1つ、ランダム）
│ └──────────────────┘    │
│ [開く] [◎焦点] [⟷つなぐ] [⋯]│  主な操作（横に並べる）
└──────────────────────────┘
```

- プレビューの操作は**3つ＋その他**に絞る。
  - 「動かす」「編集」「削除」は「⋯」の中に入れる。
  - 今は6つが横に並んでいて、はみ出している。

### C. 星のページ（「開く」または上に引く）

シートの高さは画面の**約9割**。上から順に並べる。

```
│ ‹ 道のり                   │
│ ● プラトン       [たたむ] × │
│   人物・哲学・確かさ         │
│ 概要                       │
│ [◎焦点] [⟷つなぐ] [✎編集] [⋯]│
│──────────────────────────│
│ 記述（4）        [＋記述を追加]│
│   （話題なし）               │
│   ┌ 出典あり ─── 詳しく ┐    │
│   │ ソクラテスの弟子である。 │    │
│   └────────────────┘    │
│   ✦ 雑学                    │
│   ┌ …                ┐    │
│ 意味のつながり（2）          │
│ つながりの候補（3）          │
│ この星が出てくる記述（5）      │
│ 詳細（別名・タグ・登録日・出どころ）│
```

- 並び順の考え方：**この星のこと → ほかの星とのつながり → 補足情報**
- 「詳しく」を押すと、その記述の出典・確認メモ・調べるボタン・確認の操作が開く（実装済み）。

### D. まだ知らない星（薄い星をタップ）

```
│ ● アカデメイア（まだ知らない星） × │
│ ┌ Wikipediaより ─────────┐ │
│ │ ☑ 古代ギリシアの…神域。      │ │  文を選んで登録
│ │ ☐ リュケイオン…            │ │
│ │ [選んだ1文で登録] 記事を開く  │ │
│ └─────────────────────┘ │
│ 調べる：Google Wikipedia 論文  │
│ [＋自分で書いて登録する]        │
│ この言葉が出てくる記述（1）      │
```

### E. 探す（下部バー「🔍探す」）

画面全体に重ねて表示する（宇宙は後ろで薄く見える）。

```
┌──────────────────────────┐
│ [🔍 星・記述・出典を検索   ] ×│  開いたらすぐ入力できる
│ [哲学][歴史][物理]…▸        │  分野で絞る（横にスクロール）
│ [人物][概念]… [未確認][異論]  │  種類・確認状態で絞る
│──────────────────────────│
│ ● ソクラテス      哲学・人物  │
│   …アテナイ出身の古代…       │  一致した文の一部
│ ● プラトン        哲学・人物  │
└──────────────────────────┘
```

- 結果を押すと、探す画面が閉じ、宇宙の視点がその星へ飛んでプレビューが開く。

### F. リスト（下部バー「☰リスト」）

```
│ [まだ知らない星 54][未確認の事実][異論あり] │  切り替えタブ
│──────────────────────────│
│ アカデメイア    ← プラトン から   │
│ デルポイの神託  ← 無知の知 から    │
```

- 「未確認の事実」のタブは、ファクトチェックを続けるための入口にする。

### G. その他（下部バー「⋯」）

```
│ データ                        │
│   バックアップを書き出す（JSON） │
│   バックアップから復元する       │
│ 初期セット                     │
│   初期セットを追加／まとめて削除  │
│ 表示                          │
│   星の名前の表示量（少なめ／普通／多め）│
│ この宇宙について                │
│   星・記述・出典・確認済みの数    │
```

### H. フォーム（星の追加・編集、記述、つながり）

- 下から出る**全画面に近いシート**で表示する（実装済み）。
- 「キャンセル」と「保存」は**一番下**に置き、親指で押せるようにする。
- 入力欄の文字は16px以上にする。iPhoneが自動で拡大しないようにするため（実装済み）。

## 4-4. 情報の見せ方（強弱のルール）

| 情報 | 見せ方 |
|---|---|
| 事実と意見 | 意見は点線の枠と斜体で、事実と必ず区別する |
| 確認状態 | 記述ごとに小さな札を付ける（未確認／出典あり／確認済み／異論あり） |
| 星の確かさ | プレビューに「事実〇件中 確認済み〇件」 |
| 雑学 | プレビューで目立つカードにする（暇なときの楽しみ） |
| リンク | 本文中で下線付きの文字。まだ知らない星へのリンクは点線 |
| 出典 | 「詳しく」を開くまで隠す（読みやすさを優先） |
| 数 | 上部バーに小さく常に出す |

## 4-5. 指の操作の割り当て

| 操作 | 宇宙で | シートで |
|---|---|---|
| タップ | 星を選ぶ／何もない所で閉じる | ボタン・リンク |
| 1本指ドラッグ | 視点を回す | 上下にスワイプでシートを開く・たたむ・閉じる（案） |
| 2本指 | ズーム・移動 | ― |
| ダブルタップ | 星に焦点を合わせる | ― |
| 長押し | 星をつかんで動かす（案） | ― |

- 今は「動かす」ボタンで移動モードに入る。**長押しで直接動かす**案は決めたいこと③。
- 今は、シートの開閉はボタンだけ。**スワイプで開閉する**案は決めたいこと②。

## 4-6. 状態ごとの表示

| 状態 | 表示 |
|---|---|
| 読み込み中 | 「宇宙を読み込み中…」 |
| 星が0個 | 中央に「＋で最初の星を追加」 |
| 検索で0件 | 「見つかりませんでした」と、新しい星として追加するボタン |
| オフライン | Wikipedia・外部検索の部分だけ「ネットにつながっていません」。ほかはそのまま使える |
| 保存の失敗 | 上部に赤い帯で知らせる（実装済み） |
| 削除の直後 | 下に「元に戻す」（実装済み） |

## 4-7. アプリへ翻訳するときのメモ

- 下部バーは、iPhoneアプリの**タブバー**にそのまま置き換えられる。
- シートは、iOS標準の**シート（ハーフモーダル）**に置き換えられる。
- 移動モードの代わりに、長押しでつかむ操作はアプリでも自然に使える。

## 決めたこと

| # | 論点 | 結論 |
|---|---|---|
| ① | 主な操作の置き場所 | **A**：下部バーに「探す・リスト・＋追加・その他」（3案を試しブランチで実際に触って決定） |
| ② | シートの開閉 | **B**：ボタンだけ（スワイプは使わない） |
| ③ | 星を動かす操作 | **B**：星を長押ししてそのまま動かす（移動モードはなくす） |
| ④ | 道のりの表示 | **A**：シートの上部に `ソクラテス › プラトン › …` と出し、押すとそこへ戻れる |

### ①の見比べ方

- `try/layout-a`・`try/layout-b`・`try/layout-c` の3つの試しブランチを作る。違いは `src/config/layout.ts` の1行だけ。
- 公開の自動作業が、main と一緒に3つを別々のURLで公開する。
  - `https://kzts6phvy8-spec.github.io/3DMM/try/a/`
  - `https://kzts6phvy8-spec.github.io/3DMM/try/b/`
  - `https://kzts6phvy8-spec.github.io/3DMM/try/c/`
- 3つは同じサイトなので、**保存されるデータは共通**（どれで登録しても、ほかの案でも見える）。
- 決まったら、選んだ案を main に入れ、試しブランチは片付ける。
