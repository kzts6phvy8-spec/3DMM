## セキュリティの点検（2026-11-27、あなたの依頼）

公開前に、次を確かめて報告する。見つかった問題は、直すものをあなたと決めてから直す。

- 鍵の扱い：アプリ（公開されるファイル）とリポジトリに、秘密の鍵（Supabaseの secret・service_role、Gemini・Stripe の鍵）が入っていないか。履歴も含めて
- データベースの権限（Supabase の RLS）：ほかの人のデータを読めない・書けないか。有料かどうか（profiles.plan）を本人が書き換えられないか。AIの回数を本人がごまかせないか
- 外から呼べる関数（Edge Function：ai-search・billing）：ログインの確認、入力の確認、Stripe からの通知の署名の確認
- 画面：記述・バックアップ・友達の宇宙カードなど、外から入る文字で、悪いスクリプトが動かないか（XSS）
- 使っている部品（npm のパッケージ）に、知られた脆弱性がないか（npm audit）
- バックドア（隠れた入口）がないか：リポジトリのコード・GitHub Actions・ビルドの設定に、知らない送り先や、勝手に動く処理がないか
- 通信の送り先：アプリが送る先が、決めたもの（Supabase・PostHog・Wikipedia など）だけか
